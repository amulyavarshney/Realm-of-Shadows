# Realm of Shadows

Fantasy hidden-role party game for 5–10 players. Pass & Play locally, or Host/Join online with a 4-digit code.

## Run
```bash
npm install
npm start

# Online mode
npm run backend
```

## Scripts
| Command | Description |
|---------|-------------|
| `npm start` | Expo dev server |
| `npm test` | Game logic tests |
| `npm run typecheck` | TypeScript |
| `npm run backend` | FastAPI multiplayer server |

## Stack
Expo · React Native · TypeScript · Reanimated · FastAPI (online)

See `docs/DEPLOY.md` and `docs/PRIVACY.md`.
